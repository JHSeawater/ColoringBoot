- 상태: 채택(앱인토스는 샌드박스 실기 확인 전제)
- 사용자 의견: 따라 하기 중 뒤로가기는 추천대로(본 것으로 치지 않음). 보드에서 뒤로가기로 판이 사라지는 것은 Android에서는 상관없다. 앱인토스는 대다수 게임이 어디서든 뒤로가기를 하면 공통 종료 확인창을 띄우는 것으로 보인다 — 현재 상태와 추천을 물었고, 추천대로 토스 기본 동작에 맡기기로 했다.
- AI 정리·가정: Android 보드 뒤로가기는 확인창 없이 유지. 앱인토스 추천 = 코드를 넣지 않고 토스앱 기본 동작에 맡김. 지금 WebGL 빌드는 `HandleBack`이 `#if UNITY_ANDROID`라 들어가지 않고 `backEvent` 구독 · `closeView` · history 호출이 모두 없다. `backEvent`를 구독하면 기본 뒤로가기가 차단되어 모달과 종료를 직접 만들어야 하고, SDK는 `AIT.CloseView`를 폐기 예정으로 표시한다.
- 근거: 공식 게임 출시 가이드(뒤로 또는 종료 · 종료 시 확인 모달) · 공식 이벤트 문서(구독 시 기본 동작 차단) · 릴리즈 노트 2.9.2(게임 X 버튼 종료 모달). 구독하지 않을 때 시스템 뒤로가기에 모달이 뜬다는 내용은 공식 문서에 없고 개발자 커뮤니티 답변(2026-03)뿐이며, 빈 스택에서 반응이 없었다는 제보도 있다 → 샌드박스 실기 확인이 필요하다.
- 영향: `GameFlow.HandleBack` · `Docs/TDD.md` §8. 앱인토스 쪽은 코드 변경 없음.
